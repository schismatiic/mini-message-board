# Mini Message Board

A simple message board built with **Node.js, Express, and EJS**. Users can view existing messages, submit new messages through a form, and open individual pages to view message details.

## Features

- View all messages
- Submit new messages
- View individual message details
- Server-side rendering with EJS
- Form handling with Express
- Dynamic routing
- Reusable EJS views

## Technologies

- Node.js
- Express
- EJS
- HTML
- Tailwind CSS

## Installation

Clone the repository and install the dependencies:

```bash
git clone https://github.com/schismatiic/mini-message-board
cd mini-message-board
npm install
```
